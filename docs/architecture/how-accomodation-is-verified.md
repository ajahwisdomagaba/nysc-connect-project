# NYSC Connect: How Accommodation Is Verified

*Version 1.0 (MVP)*

## The short version

Corps Members can only see accommodation listings that an admin has approved. Landlords and agents who submit listings are checked first, and each listing is checked again before it is published. Every check is done by a person. This page explains what is checked, what is not, and what you should still do yourself.

## The two checks

|  | Check 1: Account verification | Check 2: Listing approval |
| :---- | :---- | :---- |
| Who is checked | The landlord or agent | Each property that is submitted |
| What the admin looks at | The verification documents: an identity document and proof of authority | The listing details and photos |
| Result | Verified or Verification Rejected | Approved or Rejected |
| What a pass means | The person may submit listings | The listing is published |

Passing the first check does not publish anything. A verified landlord or agent can submit a listing, but it stays hidden until an admin approves it.

## Check 1: Account verification

A landlord or agent must send two documents and make one promise before they can submit any listing.

* An identity document: NIN, voter's card (PVC), driver's licence, or international passport.

* Proof of authority. A landlord sends a utility bill (with the prepaid meter number) or proof of ownership. An agent sends a landlord approval letter or an agency registration document.

* A promise not to charge any inspection or mobilization fee.

An admin reads the documents by hand. If they are accepted, the account becomes Verified. If not, the account is Verification Rejected and the person sees the reason. They can correct their documents and send them again. The documents are stored securely and are never shown publicly.

## Check 2: Listing approval

Every submitted listing starts as Pending Admin Review and is not visible to Corps Members. An admin reviews it and decides:

* Approved: the listing is published.

* Rejected: the listing is not published. The reason is recorded and shown to the person who submitted it.

Admins approve or reject listings. A rejected listing is not sent back for editing. The landlord or agent corrects the details and submits a new listing.

If a landlord or agent edits a published listing, it goes back to Pending Admin Review until an admin approves it again.

## Where listings come from

Some listings come from verified landlords and agents. Others are added by NYSC Connect admins from other sources. Every listing shows its source, so you can see where the information came from.

## How fresh is the information?

Each listing shows when it was last updated. If it has not been updated for 30 days, it is marked "may be outdated". This label tells you how recent the information is. It does not mean the information was checked on that date.

## What happens when someone reports a listing

Any Corps Member can report a listing or a Local Guide entry as Outdated, Incorrect, Misleading, or Suspicious. The report goes to an admin review queue. The admin can resolve it, dismiss it, or take action on the item. If a scam report is confirmed, the listing is hidden.

## What verification does and does not mean

| It does mean | It does not mean |
| :---- | :---- |
| An admin reviewed the documents the landlord or agent sent. | That ownership has been proven in law. NYSC Connect does not check ownership beyond the documents sent and the admin review. |
| An admin approved the listing before it was published. | That every detail on the listing is correct. |
| The landlord or agent agreed not to charge an inspection or mobilization fee. | That the property is safe or that a deal is guaranteed. |

## Limits of this release

* All reviews are manual. There is no automatic reading of documents and no check against any government database.

* There is no verified badge for landlords or agents.

* Admins approve or reject listings. They do not send a listing back for editing.

* There is no booking, payment, or chat in the app.

* How long a review takes: pending confirmation from the Product Management team.

**What you should still do**

Check the source and last updated date. Confirm the details yourself before you pay anything. Report any listing that looks wrong.
